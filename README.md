### 🚀 Proyectos Destacados

#### 1. **Milito Sabores Admin** — *Gestión Gastronómica, Escandallo y Cotización Automatizada*
Plataforma web multiusuario para el control de inventario de materias primas, cálculo de costos de recetas (ingredientes, subrecetas y consumo energético) y cotización en tiempo real.
* **Arquitectura:** React 19 + Vite en el cliente, API REST serverless en Cloudflare Workers (Hono + TypeScript) y PostgreSQL en Supabase con control de acceso basado en roles (RBAC/RLS).
* **Motor de Scraping:** Sistema de extracción en 3 niveles (*Mobile UA*, *Search Crawler* y *Proxy Headless*) capaz de leer datos estructurados (JSON-LD, VTEX, Next.js) en supermercados chilenos y normalizar precios por unidad base.

#### 2. **VitrineAndo** — *Comparador y Rastreador Histórico de Precios*
Aplicación Web orientada al monitoreo, comparación y análisis histórico de precios en supermercados mediante cálculo automático de costo unitario por formato.
* **Arquitectura:** Frontend PWA con gráficos históricos interactivos (Recharts) y API serverless en Cloudflare Pages Functions (Hono) conectada a Supabase.
* **Recolección de Datos:** Scraper automatizado local con Puppeteer Extra, Stealth Plugin y Adblocker que combina búsqueda por etiquetas semánticas y selectores CSS dinámicos.

#### 3. **MilitoRewards Twitch** — *Plataforma de Recompensas e Interacción en Tiempo Real*
Sistema de fidelización para transmisiones en vivo que permite a los espectadores acumular puntos virtuales y canjearlos por alertas multimedia dinámicas (video con chroma key, audio y TTS) proyectadas directamente en OBS Studio.
* **Arquitectura:** Extensión de Twitch en React 19 + TypeScript, backend serverless en Cloudflare Workers con validación criptográfica (JWT/HMAC) para webhooks de Twitch EventSub y sincronización instantánea mediante Supabase Realtime.
